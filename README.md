# Evenly

A simple, account-free group expense splitter. Everything lives in the URL hash—no sign-ups, no limits, no tracking.

## Features
- Add group members and expenses in seconds
- Automatic minimum-transfer settlement ("who owes whom")
- Shareable URL containing the full state
- One-click plain-text summary for messaging apps
- Supports VND, USD, EUR, JPY and Vietnamese / English
